# 小组件效果生成

无需登录，按「填我的 → 填对方 → 预览与保存」依次操作，配置双方头像、ID、消费与商品图片，分别生成 680×680 直角、无外围边线的 PNG。参考已确认的淡粉 / 奶黄视觉稿，支持图片裁切、原图模式、透明贴纸、白色描边和柔和阴影。演示照片为 AI 生成的示例素材；用户上传的照片不经过图片生成服务。

## 手机桌面模拟

保存页可切换「手机桌面效果」和「单张小组件」。默认使用用户确认的手机截图及 iPhone 16 Pro 分辨率 1206×2622；预设 iPhone 16 / 17 Pro 系列和几款安卓机型，也可手动输入像素尺寸。上传自己的完整截图后可一键采用截图原始分辨率，保留状态栏、图标及 Dock。背景支持铺满裁切或完整显示，两个组件可分别隐藏、拖动、吸附网格、手动填写占屏宽度百分比，并选配组件名称。

模拟图按所选分辨率原尺寸输出 PNG。预览直接显示导出的 Canvas，选中虚线由独立编辑层提供，导出不包含选中框、网页控件及手机外壳。单张组件背景铺满四角；仅手机桌面模拟时按所选平台裁成圆角。iPhone 使用小号组件尺寸比例；安卓使用通用比例，各品牌桌面可自行微调。更换为不同宽高比时，原截图可能裁切或留空；选择与截图一致的分辨率可完整保留原图。

为控制移动设备内存，自定义宽度 320–4096，高度 320–8192，总像素不超过 1600 万。手机背景最多 30 MB、5000 万像素，不经过商品图的 1600 像素缩小处理。用户上传截图仅在当前设备内存使用，不写入仓库；默认示例截图随应用公开发布。

## 免费抠图

采用 [IMG.LY background-removal-js](https://github.com/imgly/background-removal-js) 1.7.0，使用 `isnet_quint8` 模型，在浏览器 Worker 中运行。首次使用从 IMG.LY 官方 CDN 下载约 40 MB 模型及运行资源。CPU 性能、WebView 能力与 CDN 网络影响实际速度；失败时可重试或上传已有透明 PNG。没有付费 API 调用，不上传商品图片。此测试方案不承诺第三方 CDN 的长期可用性。

本项目在 AGPL-3.0-only 下发布，完整许可见 LICENSE.md。浏览器抠图库版权归 IMG.LY；ONNX Runtime 归微软及贡献者，依赖许可随构建保留。静态发布包包含完整源代码 `source.zip`，网页底部提供源码仓库入口。

## 开发

Node.js 20+。执行 `npm ci`、`npm test`、`npm run build`、`npm run serve`。本地地址 http://127.0.0.1:4173 。

## 替换阿里云

在 `config.js` 设置 `provider: 'api'` 与 `apiUrl`。`background.js` 的适配器支持 multipart 的 `file` 字段，服务端直接返回图片二进制，或 `{code:0,data:{imageUrl:'https://…'}}`。后端保管凭据、调用 SegmentCommonImage，并处理 CORS 和临时图片读取。GitHub Pages 不运行服务端代码，不保管访问密钥。

## 数据与限制

仅姓名 / ID、分类、金额、时间文本保存在当前浏览器 localStorage，刷新后头像与商品恢复示例；上传的图片在内存里处理，不写入仓库。商品图和头像最多 20 MB，解码后缩放至最长边 1600。金额 0–999999.99，分类与 ID 最多 12 字。单张小组件导出为 680×680 PNG；手机模拟图按所选屏幕分辨率导出。

保存优先调用系统文件分享，不支持时请求下载并提供图片预览。App 内直接存相册需后续接入实际原生桥接协议；未将普通浏览器下载视为相册保存。
