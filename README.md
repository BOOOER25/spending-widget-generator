# 小组件效果生成

## 小组件视频（v13）

视频顶部标题与时钟已移除，保留空白供社媒叠加素材。默认时间轴从 07:00（更早有消费则提前）逐小时推进到 23:00，所有空小时保留等长时间槽；同一小时内按分钟顺序更新。当前时段仅在网页进度条下提示，不进入导出画面。左 / 右组件分别可配置显示或隐藏时间，控制小型消费时间、今日对比的双方上一条时间与更新时间、本月对比更新时间；排序和金额不受影响，旧草稿默认显示。

小型商品、金额与分类作为一组从下方缩放弹入，轻微超调后落位；今日消费对比的两侧上一条记录分别弹入，只更新发生消费的一侧。入场约 0.58 秒，旧记录短暂上移淡出。组件插画边框和头像固定。预览、任意拖动和录制采用同一时间函数。

消费发生后，累计金额和当前消费金额以 0.62 秒缓动变化，双方对比比例与月分类条同步更新；摘要栏浮现本笔新增金额。动效由时间轴直接计算，拖动、倒放检查与视频录制结果一致，结束时金额精确落到分。

首页「小组件视频」进入 `video.html`，也可直接配置此 H5 链接。沿用双人贴纸的 9:16 背景及双方累计对比栏，将商品区域替换为动态小组件。

- 双方各最多 18 笔，独立配置名称、金额、分类、分类图标、消费时间、图片及大小；支持上传、免费抠图和复用素材。
- 默认按逐小时时间轴自动安排出现时间，到达消费时刻更新对应组件。相同时刻的多笔共同计入。可改用手动出现秒数。
- 两个组件独立选择真小组件、假小组件、今日消费对比或本月消费对比。小型左右摆放；含中型时分行展示，保持原稿比例。上方累计栏显示本段视频的消费总额。
- 真 / 假小组件显示当前最新商品；今日对比累计双方金额、比例和最近一笔；本月对比累计金额、笔数及分类，可配置期初金额和笔数。分类超过三项时，保留金额最高的两项并将其余合并为「其他」，避免遗漏。
- 配置时长 4–60 秒，可拖动进度预览或播放，保存 1080×1920 当前画面，录制 720×1280 / 1080×1920、30 fps 视频。浏览器支持 MP4 时优先 MP4，否则使用 WebM 并显示实际格式；可上传背景音乐。录制按实际时长进行，需保持页面前台，支持取消。
- 视频草稿、图片和音乐存入独立 IndexedDB，不覆盖图片编辑器配置。无登录、无服务器处理；初次打开不下载字体或抠图模型，只有主动抠图时加载模型。样式下载失败可重试，未就绪时禁止保存或录制占位画面。

视频实现复用当前工作区双人贴纸工作室的编辑、素材、IndexedDB 和录制流程，`video/core.js` 统一时间轴与金额规则，`video/draw.js` 调用现有组件渲染器，不使用图片生成服务。

无需登录，通过「截图 / 左组件 / 右组件」切换编辑，修改后实时预览。分别配置两侧头像、名称、消费金额、今日总额与商品图片，生成 680×680 直角正方形 PNG。黄色细边框、白色内容底，商品与两行文字居中。支持图片裁切、原图模式、透明贴纸、白色描边和柔和阴影。用户上传的照片不经过图片生成服务。

名称使用黑色常规字重，金额使用粉色粗体；两行均按 170px 设计尺寸应用 1px 白色描边、偏移 1px / 模糊 5px / 10% 黑色阴影。导出时等比放大。右上角今日总额取消胶囊底：半透明粉色「今日:」与粉色「￥」使用 8px 粗体，金额使用 13px 粗体，整体靠右并共用基线，应用偏移 1px / 模糊 5px / 8% 黑色阴影。整数总额不显示 .00，非整数总额保留两位小数。默认使用设备系统字体，不下载字体文件。配置中可主动选择「阿里普惠体 + Inter」，此时才下载约 4.3 MB 字体；下载期间可继续编辑或切回系统字体。所选字体未就绪时暂停保存，失败可重试；完成后统一刷新预览与导出，避免导出字体不一致。Inter 使用 SIL OFL（见 Inter-OFL.txt）；普惠体来自 AlibabaPuHuiTi 3.0。

## 可配置组件样式（v10）

左右组件可独立选择四种样式，原有样式命名为「假小组件（原样式）」，新增三种真组件：

| 样式 | 配置内容 | 单独导出尺寸 |
|---|---|---|
| 假小组件（原样式） | 头像、名称、金额、今日总额、商品图片 | 680×680 |
| 真小组件 | 头像、商品图片、消费金额、分类、消费时间 | 444×444 |
| 今日消费对比 | 双方头像及名称、今日总额、最近一笔金额 / 分类 / 时间、更新时间 | 966×444 |
| 本月消费对比 | 双方头像、本月总额与笔数、各三个分类名称 / 金额 / 图标、更新时间 | 966×444 |

新样式参考用户提供的 1 / 2 / 3 / 4 系列 @3x PNG：小组件设计尺寸 148×148，中组件 322×148，按 3 倍图原尺寸输出。保留原稿插画边框与猫咪装饰，数据通过 Canvas 动态绘制，不把原稿文字当作可编辑结果。真小组件支持两种顶部装饰；三种真组件可选黄色、薄荷绿或透明外底。今日对比占比按双方总额自动计算；均为零时显示 0%。本月左右分类数据独立配置。

手机预览按模板长宽比计算组件高度、圆角和拖动区域；切换为中组件时默认分行排列，大小可继续调整。默认仍使用系统字体，模板装饰仅在选择相应真组件后加载，失败可重试。

文本配置和样式选择保存在当前浏览器，上传图片仅保存在当前页面内存。切换样式保留已填写的数据。

## 手机截图模式（v9）

暂时停用预设机型、纯壁纸、模拟状态栏 / Dock、背景透明度、缩放与位置配置。原实现保留在 `phone-background-legacy.js` 与 `background-panel-legacy.html`，不导入当前页面。初次打开不下载默认背景、桌面图标或字体，不启动抠图模型。示例商品与头像独立加载，失败不阻塞截图上传与编辑。

用户上传 JPG、PNG 或 WebP 手机截图后，直接采用图片原始宽高建立画布；背景按 1:1 像素绘制，不裁切、不缩放、不重复叠加桌面元素。未上传前明确提示上传，手机效果图不可保存；单个组件仍可编辑和保存。更换截图也自动更新原始分辨率，读取失败保留上一张。

两个组件可分别隐藏、拖动、吸附网格、手动填写占屏宽度百分比。组件下方名称始终显示「喵喵记账」，不可修改。

手机效果图按截图原始分辨率输出 PNG。预览直接显示导出的 Canvas，选中框来自独立编辑层，导出不含网页控件和手机外壳。假小组件为 680×680；真组件尺寸见上表。仅手机截图中的组件使用配置圆角。

截图宽度支持 320–4096，高度 320–8192，总像素不超过 1600 万，文件不超过 30 MB。超出支持范围时明确提示并保留上一张截图。上传图片仅在当前设备处理，默认示例素材随应用公开发布。

## 免费抠图

采用 [IMG.LY background-removal-js](https://github.com/imgly/background-removal-js) 1.7.0，使用 `isnet_quint8` 模型，在浏览器 Worker 中运行。首次使用从 IMG.LY 官方 CDN 下载约 40 MB 模型及运行资源。CPU 性能、WebView 能力与 CDN 网络影响实际速度；失败时可重试或上传已有透明 PNG。没有付费 API 调用，不上传商品图片。此测试方案不承诺第三方 CDN 的长期可用性。

本项目在 AGPL-3.0-only 下发布，完整许可见 LICENSE.md。浏览器抠图库版权归 IMG.LY；ONNX Runtime 归微软及贡献者，依赖许可随构建保留。静态发布包包含完整源代码 `source.zip`，网页底部提供源码仓库入口。

## 开发

Node.js 20+。执行 `npm ci`、`npm test`、`npm run build`、`npm run serve`。本地地址 http://127.0.0.1:4173 。

## 替换阿里云

在 `config.js` 设置 `provider: 'api'` 与 `apiUrl`。`background.js` 的适配器支持 multipart 的 `file` 字段，服务端直接返回图片二进制，或 `{code:0,data:{imageUrl:'https://…'}}`。后端保管凭据、调用 SegmentCommonImage，并处理 CORS 和临时图片读取。GitHub Pages 不运行服务端代码，不保管访问密钥。

## 数据与限制

图片编辑器的文本和样式配置保存在当前浏览器 localStorage，刷新后头像与商品恢复示例；上传的图片在内存里处理，不写入仓库。商品图和头像最多 20 MB，解码后缩放至最长边 1600。金额 0–999999.99，名称最多 24 字。组件按所选模板尺寸导出 PNG；手机效果图按上传截图原始分辨率导出。视频编辑器单独保存 IndexedDB 草稿，图片最长边 1400，单图 / 音乐 20 MB，素材库最多 100 项；清除浏览器数据会清除草稿。

保存优先调用系统文件分享，不支持时请求下载并提供图片预览。App 内直接存相册需后续接入实际原生桥接协议；未将普通浏览器下载视为相册保存。
