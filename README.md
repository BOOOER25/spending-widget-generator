# 小组件效果生成

无需登录，通过「截图 / 左组件 / 右组件」切换编辑，修改后实时预览。分别配置两侧头像、名称、消费金额、今日总额与商品图片，生成 680×680 直角正方形 PNG。黄色细边框、白色内容底，商品与两行文字居中。支持图片裁切、原图模式、透明贴纸、白色描边和柔和阴影。用户上传的照片不经过图片生成服务。

名称使用黑色常规字重，金额使用粉色粗体；两行均按 170px 设计尺寸应用 1px 白色描边、偏移 1px / 模糊 5px / 10% 黑色阴影。导出时等比放大。右上角今日总额取消胶囊底：半透明粉色「今日:」与粉色「￥」使用 8px 粗体，金额使用 13px 粗体，整体靠右并共用基线，应用偏移 1px / 模糊 5px / 8% 黑色阴影。整数总额不显示 .00，非整数总额保留两位小数。默认使用设备系统字体，不下载字体文件。配置中可主动选择「阿里普惠体 + Inter」，此时才下载约 4.3 MB 字体；下载期间可继续编辑或切回系统字体。所选字体未就绪时暂停保存，失败可重试；完成后统一刷新预览与导出，避免导出字体不一致。Inter 使用 SIL OFL（见 Inter-OFL.txt）；普惠体来自 AlibabaPuHuiTi 3.0。

## 手机截图模式（v9）

暂时停用预设机型、纯壁纸、模拟状态栏 / Dock、背景透明度、缩放与位置配置。原实现保留在 `phone-background-legacy.js` 与 `background-panel-legacy.html`，不导入当前页面。初次打开不下载默认背景、桌面图标或字体，不启动抠图模型。示例商品与头像独立加载，失败不阻塞截图上传与编辑。

用户上传 JPG、PNG 或 WebP 手机截图后，直接采用图片原始宽高建立画布；背景按 1:1 像素绘制，不裁切、不缩放、不重复叠加桌面元素。未上传前明确提示上传，手机效果图不可保存；单个组件仍可编辑和保存。更换截图也自动更新原始分辨率，读取失败保留上一张。

两个组件可分别隐藏、拖动、吸附网格、手动填写占屏宽度百分比。组件下方名称始终显示「喵喵记账」，不可修改。

手机效果图按截图原始分辨率输出 PNG。预览直接显示导出的 Canvas，选中框来自独立编辑层，导出不含网页控件和手机外壳。单张组件仍为 680×680，背景铺满四角；仅手机截图中的组件使用圆角，白底与外框同心，边框等距内缩 6/170。

截图宽度支持 320–4096，高度 320–8192，总像素不超过 1600 万，文件不超过 30 MB。超出支持范围时明确提示并保留上一张截图。上传图片仅在当前设备处理，默认示例素材随应用公开发布。

## 免费抠图

采用 [IMG.LY background-removal-js](https://github.com/imgly/background-removal-js) 1.7.0，使用 `isnet_quint8` 模型，在浏览器 Worker 中运行。首次使用从 IMG.LY 官方 CDN 下载约 40 MB 模型及运行资源。CPU 性能、WebView 能力与 CDN 网络影响实际速度；失败时可重试或上传已有透明 PNG。没有付费 API 调用，不上传商品图片。此测试方案不承诺第三方 CDN 的长期可用性。

本项目在 AGPL-3.0-only 下发布，完整许可见 LICENSE.md。浏览器抠图库版权归 IMG.LY；ONNX Runtime 归微软及贡献者，依赖许可随构建保留。静态发布包包含完整源代码 `source.zip`，网页底部提供源码仓库入口。

## 开发

Node.js 20+。执行 `npm ci`、`npm test`、`npm run build`、`npm run serve`。本地地址 http://127.0.0.1:4173 。

## 替换阿里云

在 `config.js` 设置 `provider: 'api'` 与 `apiUrl`。`background.js` 的适配器支持 multipart 的 `file` 字段，服务端直接返回图片二进制，或 `{code:0,data:{imageUrl:'https://…'}}`。后端保管凭据、调用 SegmentCommonImage，并处理 CORS 和临时图片读取。GitHub Pages 不运行服务端代码，不保管访问密钥。

## 数据与限制

仅名称、消费金额、今日总额文本保存在当前浏览器 localStorage，刷新后头像与商品恢复示例；上传的图片在内存里处理，不写入仓库。商品图和头像最多 20 MB，解码后缩放至最长边 1600。金额 0–999999.99，名称最多 24 字。单张小组件导出为 680×680 PNG；手机效果图按上传截图原始分辨率导出。

保存优先调用系统文件分享，不支持时请求下载并提供图片预览。App 内直接存相册需后续接入实际原生桥接协议；未将普通浏览器下载视为相册保存。
