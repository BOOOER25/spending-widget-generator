# 小组件效果生成

无需登录，通过「背景 / 左组件 / 右组件」切换编辑，修改后实时预览。分别配置两侧头像、名称、消费金额、今日总额与商品图片，生成 680×680 直角正方形 PNG。黄色细边框、白色内容底，商品与两行文字居中。支持图片裁切、原图模式、透明贴纸、白色描边和柔和阴影。用户上传的照片不经过图片生成服务。

名称使用黑色常规字重，金额使用粉色粗体；两行均按 170px 设计尺寸应用 1px 白色描边、偏移 1px / 模糊 5px / 10% 黑色阴影。导出时等比放大。右上角今日总额取消胶囊底：半透明粉色「今日:」与粉色「￥」使用 8px 粗体，金额使用 13px 粗体，整体靠右并共用基线，应用偏移 1px / 模糊 5px / 8% 黑色阴影。整数总额不显示 .00，非整数总额保留两位小数。数字使用 Inter，中文回退阿里巴巴普惠体 3.0 Regular。字体加载完成后才生成组件，避免首张导出字体跳变。Inter 使用 SIL OFL（见 Inter-OFL.txt）；普惠体来自 AlibabaPuHuiTi 3.0。

## 手机桌面模拟

保留 iPhone 16 / 17 Pro 系列、Samsung S25 Ultra、Xiaomi 15 Ultra、Pixel 10 Pro 机型预设。

- **纯壁纸**：按所选机型分辨率展示，自动叠加模拟状态栏、Dock 和底部桌面元素。iPhone 添加模拟灵动岛。Dock 使用从官方发行者 App Store 条目下载的真实图标，所有 Dock 均含微信；安卓使用微信、支付宝、淘宝、QQ。来源记录见 assets/icons/，品牌及图标权利归各自权利人。
- **完整手机截图**：上传后自动采用图片原始像素尺寸，保留原有状态栏、图标和 Dock，不重复叠加桌面元素。

背景可调整不透明度（0–100%，白色底）、缩放（100–300%）、水平与垂直位置。开启「调整背景位置」后可直接拖动预览中的背景；点击完成后继续操作组件。上传新背景时恢复 100% 不透明度、100% 缩放和居中位置。完整截图在默认调整值下保留原始像素。

两个组件可分别隐藏、拖动、吸附网格、手动填写占屏宽度百分比。组件下方名称始终显示「喵喵记账」，不可修改。

模拟图按当前分辨率原尺寸输出 PNG。预览直接显示导出的 Canvas，选中框来自独立编辑层，导出不含网页控件和手机外壳。单张组件背景铺满四角，仅手机桌面模拟使用圆角；模拟图内层白底与外层组件采用同心圆角，边框等距内缩 6/170，随圆角配置同步变化。模拟桌面元素与系统真实截图可能存在视觉差异；需要保留真实桌面时使用完整手机截图模式。

宽度支持 320–4096，高度 320–8192，总像素不超过 1600 万。背景最多 30 MB、5000 万像素，不经过商品图片的缩小处理。超出支持范围时明确提示并保留上一张背景。上传图片仅在当前设备处理，默认示例素材随应用公开发布。

## 免费抠图

采用 [IMG.LY background-removal-js](https://github.com/imgly/background-removal-js) 1.7.0，使用 `isnet_quint8` 模型，在浏览器 Worker 中运行。首次使用从 IMG.LY 官方 CDN 下载约 40 MB 模型及运行资源。CPU 性能、WebView 能力与 CDN 网络影响实际速度；失败时可重试或上传已有透明 PNG。没有付费 API 调用，不上传商品图片。此测试方案不承诺第三方 CDN 的长期可用性。

本项目在 AGPL-3.0-only 下发布，完整许可见 LICENSE.md。浏览器抠图库版权归 IMG.LY；ONNX Runtime 归微软及贡献者，依赖许可随构建保留。静态发布包包含完整源代码 `source.zip`，网页底部提供源码仓库入口。

## 开发

Node.js 20+。执行 `npm ci`、`npm test`、`npm run build`、`npm run serve`。本地地址 http://127.0.0.1:4173 。

## 替换阿里云

在 `config.js` 设置 `provider: 'api'` 与 `apiUrl`。`background.js` 的适配器支持 multipart 的 `file` 字段，服务端直接返回图片二进制，或 `{code:0,data:{imageUrl:'https://…'}}`。后端保管凭据、调用 SegmentCommonImage，并处理 CORS 和临时图片读取。GitHub Pages 不运行服务端代码，不保管访问密钥。

## 数据与限制

仅名称、消费金额、今日总额文本保存在当前浏览器 localStorage，刷新后头像与商品恢复示例；上传的图片在内存里处理，不写入仓库。商品图和头像最多 20 MB，解码后缩放至最长边 1600。金额 0–999999.99，名称最多 24 字。单张小组件导出为 680×680 PNG；手机模拟图按所选屏幕分辨率导出。

保存优先调用系统文件分享，不支持时请求下载并提供图片预览。App 内直接存相册需后续接入实际原生桥接协议；未将普通浏览器下载视为相册保存。
